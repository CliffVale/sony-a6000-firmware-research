# Contributing

Thanks for thinking about contributing to this project. Here's how to get started.

## Getting Started

1. Fork the repo
2. Clone your fork
3. Create a branch: `git checkout -b your-feature`
4. Make your changes
5. Commit with a clear message
6. Push and open a PR

## Commit Messages

We follow [Conventional Commits](https://www.conventionalcommits.org/):

```
type(scope): short description

optional body
```

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

## Pull Requests

- Keep PRs focused on one change
- Include a clear description of what changed and why
- Add tests if you're changing behavior
- Make sure CI passes

## Issues

- Use the provided templates
- Be specific about your environment and steps to reproduce
- Check existing issues before opening a new one

## Code Style

- Follow the existing conventions in the codebase
- Keep changes minimal and focused
- Prefer standard library over new dependencies

## Questions?

Open an issue with the `question` label.
